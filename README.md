An entry for [One-Line Office Jokes](https://make.fun/competitions/u-markk-st-one-line-office-jokes-a51f2bcc)
on [make.fun](https://make.fun): one single line that makes office life funny.

## The line

> The office printer only jams when the document is urgent, confidential, and due in five minutes — it can smell fear.

## How it works

`main.ts` holds the joke, validates it against the competition gate
(1–199 characters, a single line, no leading or trailing white space,
ending on its punch), then writes it to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 22.23.4). No dependencies
to install.
